# Сервис асинхронного выполнения задач

## Запуск

```bash
docker compose up --build
```

Compose запускает PostgreSQL, Kafka, два экземпляра сервиса и балансировщик Nginx.
API доступен на `http://localhost:8080`, Swagger UI на `http://localhost:8080/swagger-ui.html`.

## Основные решения

- Первичный ключ - внешний `eventId`: он обеспечивает уникальность и идемпотентность без отдельного числового ID и его
  индекса.
- Получение задачи: `GET /api/tasks/{eventId}`.
- Захват строки реализован через `FOR UPDATE SKIP LOCKED` и проверку `executionId`, поэтому `@Version` не используется
- Каждый инстанс запускает `while (true) {...}` worker'ов в пуле. Если работы нет, воркер таймаутится, чтобы не ддосить
  БД
- Повторная доставка того же `eventId` с одинаковыми параметрами не создаёт новую задачу.
- В DLT отправляются только явно определённые ошибки входного сообщения. Остальные ошибки регистрации повторяются без
  ограничения, поэтому недоступность БД не приводит к переносу всех сообщений в DLT.
- Каждая попытка получает новый `executionId` и срок аренды. Каждый шаг прогресса продлевает lease.
